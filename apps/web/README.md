# apps/web

Next.js 16 app for GPON Network Management.

```bash
pnpm install
cp .env.local.example .env.local
pnpm dev
```

`pnpm check` runs lint and format checks. `pnpm build` builds for production.

Setup, environment variables and architecture: see the [root README](../../README.md) and [`CLAUDE.md`](../../CLAUDE.md).
Next.js 16 rules for agents: [`AGENTS.md`](AGENTS.md).
